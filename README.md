# SourceSlate

SourceSlate is a modern static documentation generator for PHP source code and PHPDoc.

It is designed as a straightforward alternative to legacy PHP API documentation generators: scan a PHP codebase, understand native declarations and PHPDoc, build interconnected documentation, link documentation back to source, and optionally write `@sourceslate` documentation links into PHP file headers.

The initial implementation is being established on the `main` branch.
