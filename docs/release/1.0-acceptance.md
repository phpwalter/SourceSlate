# SourceSlate 1.0 Acceptance Gate

A release candidate is eligible for `1.0.0` only when every required gate below passes.

## Installation

- [ ] `composer validate --strict` passes.
- [ ] `composer install` succeeds on PHP 8.3 and PHP 8.4.
- [ ] `composer global require phpwalter/sourceslate` exposes `sourceslate` on PATH.
- [ ] Windows, Linux, and macOS installation instructions are verified.

## Local project build

- [ ] `sourceslate .` produces a complete static documentation tree.
- [ ] Re-running the same build produces identical logical output.
- [ ] `sourceslate . --check` succeeds immediately after generation.
- [ ] Source files outside configured source roots are not scanned.
- [ ] Excluded paths are not scanned.

## Remote project build

- [ ] HTTPS repository resolution works.
- [ ] SSH repository resolution works.
- [ ] Branch, tag, full SHA, and unambiguous abbreviated SHA selection work.
- [ ] Ambiguous branch/tag and abbreviated-SHA cases fail deterministically.
- [ ] Persistent cache reuse works.
- [ ] Offline cache reuse works.
- [ ] Monorepo `--source-path` works and cannot escape the worktree.
- [ ] Submodule recursion works only when explicitly enabled.

## Cache safety

- [ ] Metadata writes are atomic.
- [ ] Repair is transactional.
- [ ] `cache:verify` detects malformed metadata and repository corruption.
- [ ] `cache:prune` cannot delete active repository state.
- [ ] `cache:clear` serializes against source resolution and repair.
- [ ] Interrupted repair and publication debris is detected or reclaimed.
- [ ] Lock hierarchy tests pass on Linux and Windows.

## Parser and PHPDoc

- [ ] Classes, interfaces, traits, enums, functions, methods, properties, constants, and enum cases are represented.
- [ ] Native nullable, union, intersection, promoted, readonly, and attribute syntax is preserved where supported by the parser model.
- [ ] `@param`, `@return`, `@throws`, `@var`, property, method, template, inheritance, deprecation, `@see`, and SourceSlate tags are preserved.
- [ ] Unknown PHPDoc tags remain lossless.
- [ ] Malformed/incomplete source fails predictably without corrupting generated output.

## Symbol resolution

- [ ] Fully-qualified type references resolve.
- [ ] Same-namespace short type references resolve.
- [ ] Methods, properties, constants, enum cases, and functions resolve.
- [ ] Ambiguous short names never resolve by guesswork.
- [ ] Generated links use deterministic renderer paths.

## Generated site

- [ ] Project, namespace, type, function, and source pages render correctly.
- [ ] Search index contains types and members.
- [ ] Search and navigation are keyboard usable.
- [ ] Long signatures and source lines remain readable on narrow screens.
- [ ] Generated text is escaped and malicious PHPDoc cannot inject executable markup.

## Source-header update

- [ ] Local source updates are idempotent.
- [ ] Existing PHPDoc content is preserved.
- [ ] Existing `@sourceslate` links are replaced rather than duplicated.
- [ ] Remote cached sources cannot be mutated.
- [ ] Dry-run mode can report source-header changes without writing files.

## CI and release

- [ ] Linux PHP 8.3 passes.
- [ ] Linux PHP 8.4 passes.
- [ ] Windows PHP 8.3 passes.
- [ ] Windows PHP 8.4 passes.
- [ ] `doctor --json` passes in CI.
- [ ] deterministic documentation `--check` passes.
- [ ] Composer release archive is generated from a version tag.

## Release quality

- [ ] No P0 or P1 defects remain open.
- [ ] Diagnostic-code reference matches implementation.
- [ ] CHANGELOG and release notes are complete.
- [ ] Upgrade/deprecation policy is documented.
- [ ] Security review is complete.
- [ ] Example projects generate successfully.

Only after every required gate is green should the package be tagged `v1.0.0`.
